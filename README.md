## 🚀 How to Run Locally

1. Open your terminal in this directory:
   ```bash
   cd c:\Users\SONA\OneDrive\Desktop\Empire\novarise
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

## 🚢 Production Build
To create an optimized production build:
```bash
npm run build
npm start
```
